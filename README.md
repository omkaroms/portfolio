# Omkar Goyarekar — Data Engineer Portfolio

A responsive, static personal portfolio website built with HTML, CSS and JavaScript. It is designed for deployment on GitHub Pages.

## Run locally
Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a new public repository named **`omkaroms.github.io`** under your GitHub account.
2. Upload `index.html`, `styles.css`, `script.js` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes publishing, visit `https://omkaroms.github.io`.

## Before publishing
- Confirm the contact details and LinkedIn URL.
- Add a downloadable PDF resume if you want a resume button.
- Replace project placeholders with public repository links, architecture diagrams and measurable outcomes only where you can share them.
- Verify certification status and dates before publishing.
- Consider whether you want your phone number displayed publicly; this starter intentionally omits it.
